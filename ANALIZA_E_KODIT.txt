================================================================================
1. RRJEDHA E PLOTË E PËRDORUESIT (END-TO-END)
================================================================================

  [Regjistrim]  /register  →  POST /api/auth/register
                →  krijon User në DB, rol "patient" automatikisht
                →  ridrejtim në /login

  [Login]       /login  →  POST /api/auth/login
                →  access_token + refresh_token në localStorage
                →  /dashboard

  [Dashboard]   /dashboard  →  GET /api/predict/history (me Bearer token)
                →  liston analizat e ruajtura (lab_tests)
                →  karta të zgjerueshme, shqip/anglisht
                →  buton → /diabetes

  [Diabet]      /diabetes
      a) Ngarkon foto/PDF  →  POST /api/predict/diabetes/extract
         →  OCR (LEADTOOLS ose demo) plotëson formularin (8 fusha)
      b) Plotëson/editon manualisht 8 vlera
      c) "Predict"  →  POST /api/predict/diabetes?persist=true
         →  ML (Random Forest + K-Means)
         →  override nëse glukozë < 70 (hipoglikemi)
         →  ruan LabTest në DB
         →  modal me probabilitet + grafikë (bar, radar, donut)

  [Logout]      Navbar  →  fshin token-at, /login

  [Mbrojtje]    Pa token: /dashboard dhe /diabetes → /login
                Me token: /login dhe /register → /dashboard

================================================================================
2. TABELAT E DATABAZËS QË PËRDOREN REALISHT
================================================================================

  Vetëm 6 grupe tabelash kanë kod aktiv (INSERT/SELECT):

  users              Regjistrim, login, /me
  refresh_tokens     Login dhe refresh token (rotation në backend)
  roles              Krijohen në start: admin, doctor, patient
  user_roles         Çdo user i ri → patient
  permissions        manage_users për admin
  role_permissions   Lidh admin ↔ manage_users
  patients           Krijohet automatikisht për user-in në parashikimin e parë
  lab_tests          Ruhet çdo parashikim (8 vlera + ml_prediction + ml_confidence)

  Të gjitha tabelat e tjera në models.py (mjekë, termine, receta, etj.)
  NUK përdoren — pa API, pa frontend.

================================================================================
3. API FUNKSIONALE
================================================================================

  Përdoren nga aplikacioni React:
  ─────────────────────────────────
  POST   /api/auth/register
  POST   /api/auth/login
  POST   /api/predict/diabetes          (?persist=true|false)
  POST   /api/predict/diabetes/extract    (upload file)
  GET    /api/predict/history

  Ekzistojnë në backend, por React NUK i thërret:
  ───────────────────────────────────────────────
  POST   /api/auth/refresh        (refresh_token ruhet por s’përdoret)
  GET    /api/auth/me             (authApi.getMe ekziston, asnjë faqe e thërret)
  GET    /api/auth/admin/users    (vetëm Swagger / klient manual)
  WS     /ws/notifications/{id}   (pa UI në frontend)
  WS     /ws/chat/{room}          (pa UI në frontend)
  GET    /health                  (kontroll serveri, jo nga app)

8. KUSHTET QË DUHEN PËR TË PUNUAR LOKALISHT
================================================================================

  Backend:
    cd backend → venv → pip install -r requirements.txt
    python -m uvicorn main:app --reload --port 8000
    (ose porti që përputhet me frontend)

  Frontend:
    cd frontend → npm install → npm run dev

  RËNDËSISHËM: axios.js ka baseURL http://127.0.0.1:7001
  Backend zakonisht është në 8000 → duhet një port i njëjtë (ndrysho axios ose uvicorn).

  ML: modelet .pkl të gjeneruara (shiko seksionin 6).

  OCR (opsional):
    LEADTOOLS i instaluar + .env
    OSE OCR_DEMO_FALLBACK=true për testim pa SDK
