2. WEB SERVER — ÇFARË PËRDORET
================================================================================

BACKEND (API):
  • Web server: Uvicorn (ASGI)
  • Komanda tipike:
      cd backend
      python -m uvicorn main:app --reload --port 8000
  • FastAPI është aplikacioni; Uvicorn e shërben në HTTP.
  • Në prodhim mund të përdoret edhe: Gunicorn + Uvicorn workers, ose
    Hypercorn — por në kodin tuaj dokumentohet Uvicorn.

FRONTEND (UI):
  • Dev server: Vite (jo Apache/Nginx për zhvillim)
  • Komanda:
      cd frontend
      npm run dev
  • Vite servon React në HTTP dhe bën Hot Module Replacement (HMR).
  • Build prodhim: npm run build → skedarë statikë në frontend/dist/
    (mund të hostohen më vonë me Nginx, Vercel, etj. — nuk është konfiguruar
     aktualisht; vercel.json është hequr nga repo).

PËRMBLEDHJE:
  | Rol              | Server softuer   |
  |------------------|------------------|
  | API REST         | Uvicorn          |
  | Faqja React      | Vite (dev)       |
  | WebSocket        | Uvicorn (i njëjti proces FastAPI) |

3. DATABAZA
================================================================================

DEFAULT (siç është në backend/app/database.py):
  • Motor: SQLite
  • URL: sqlite:///./healthconnectai.db
  • Skedari krijohet në folderin backend/ kur starton serveri.
  • Tabelat krijohen automatikisht: Base.metadata.create_all() në lifespan.

OPSIONAL (produksion / README):
  • PostgreSQL
  • Në .env: DATABASE_URL=postgresql://user:pass@host:5432/dbname
  • Skript manual SQL në skedarin "DB" në rrënjë (healthconnectaiDB) —
    për dizajn Postgres, jo i lidhur automatikisht me SQLite.

ORM:
  • SQLAlchemy — të gjitha query-t përmes modeleve në app/models.py.

TABELAT AKTIVE NË APP:
  users, refresh_tokens, roles, user_roles, permissions, role_permissions,
  patients, lab_tests

5. CILA PJESË LIDH FRONTEND-IN ME DATABAZËN
================================================================================

RREGULL I RËNDËSISHËM:
  React NUK lidhet drejtpërdrejt me databazën. Asnjë driver SQL në frontend.

Zinxhiri i plotë:

  [1] React (Dashboard, Login, DiabetesPredict)
        ↓
  [2] api/axios.js + authApi.js / predictionApi.js
        ↓  HTTP REST (JSON)
  [3] FastAPI Controllers (auth_controller, ml_controller)
        ↓
  [4] Services (AuthService, MLService) + get_db()
        ↓
  [5] SQLAlchemy Session → engine → SQLite/PostgreSQL

Shembuj konkret:

  • Historik në Dashboard:
      getPredictionHistory()
      → GET /api/predict/history
      → ml_controller.get_prediction_history
      → db.query(LabTest) …

  • Login:
      loginUser()
      → POST /api/auth/login
      → AuthService.login
      → db.query(User), INSERT refresh_tokens

  • Parashikim + ruajtje:
      predictDiabetes()
      → POST /api/predict/diabetes
      → ml_controller → INSERT lab_tests

Pjesa që është "ura" midis UI dhe DB = BACKEND (FastAPI + SQLAlchemy).

7. ALGORITMET / MODELET (MACHINE LEARNING)
================================================================================

DATASET:
  • Pima Indians Diabetes (768 rreshta, 8 features + Outcome)
  • Burim: datasets/diabetes.csv

PREPROCESSING (02_preprocessing.py):
  • Trajtim NaN (vlera 0 për disa kolona sipas konventës)
  • Heqje outliers (metoda IQR)
  • StandardScaler (normalizim)
  • Train/Test split 80% / 20%

KLASIFIKIM — 5 algoritme të trajnuara (03_train_models.py):
  1. k-Nearest Neighbors (kNN)        — k=5, distancë Euclidean
  2. Random Forest                    — 100 pemë, random_state=42
  3. Logistic Regression              — solver lbfgs
  4. MLP Neural Network (1 shtresë)   — 64 neurone, ReLU
  5. MLP Neural Network (3 shtresa)   — 128-64-32, ReLU

  NË PRODUCTION (API live):
  ★ Random Forest — parashikim diabeti (diabetes_random_forest.pkl)
  ★ StandardScaler — para se të hyjë në model

UNSUPERVISED:
  • K-Means Clustering (K=3) — grupe rreziku: i ulët / mesatar / i lartë
  • Elbow method për zgjedhjen e K
  • Përdoret bashkë me Random Forest në predict_diabetes()

TRAJNIM SHTESË (offline, jo në çdo request):
  • GridSearchCV — hyperparameter tuning (07)
  • Stratified 5-Fold Cross-Validation (08)

METRIKA:
  • accuracy, precision, recall, F1, confusion matrix
  • Rezultate në models/results.csv

RREGULLA KLINIKE (jo ML, por në kod):
  • Nëse Glucose < 70 mg/dL → override "Hipoglikemi" / rrezik i lartë
    (backend ml_controller + frontend applyClinicalOverrides)

OCR (jo ML klasik):
  • LEADTOOLS OCR — nxjerr tekst nga imazh/PDF
  • Regex + sinonime shumëgjuhëshe → mapon në 8 fusha numerike
